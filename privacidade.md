## Privacidade no 2ex-lab

O 2ex-lab procura manter a experiência simples e minimizar a coleta de dados.

### Interações com este site

Nesta primeira versão:

- não há formulários de cadastro ou contato;
- não há comentários ou áreas de usuário;
- não instalamos ferramentas próprias de publicidade ou analytics;
- não solicitamos informações pessoais ou dados sensíveis.

O site é hospedado pelo GitHub Pages. A infraestrutura do GitHub pode processar dados técnicos de acesso e segurança conforme suas próprias políticas e condições. Consulte a [Declaração de Privacidade do GitHub](https://docs.github.com/pt/site-policy/privacy-policies/github-privacy-statement).

### Links externos

Links para outros sites levam a ambientes com políticas próprias de privacidade e uso. Recomendamos consultar essas políticas antes de compartilhar informações.

### Atualizações

Esta página poderá ser atualizada quando novas funcionalidades ou serviços forem adicionados. A data de revisão será indicada quando houver alteração relevante.
